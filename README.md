# 🚕 NYC Taxi Trips 2024 – Large-Scale Data Cleaning & Analytics

This project processes and analyzes **40M+ NYC taxi trip records** to uncover insights about **demand patterns, revenue drivers, and tipping behavior**.

It simulates a real-world big data workflow, focusing on **data cleaning, scalability, and business insights generation**.

---

## 💼 Key Highlights

- Processed and cleaned **40M+ taxi trip records**  
- Built a scalable data pipeline using **chunk-based processing**  
- Identified peak demand hours and high-revenue locations  
- Generated insights to help drivers **increase revenue and tips**  

---

## 🚀 Project Overview

This project follows a structured workflow:

- **Python (Pandas)** → Data cleaning and preprocessing  
- **Chunk Processing** → Efficient handling of large datasets  
- **Data Validation** → Fixing missing, zero, and inconsistent values  
- **Power BI** → Visualization and business insights  

The final dataset is prepared for **analytics, reporting, and dashboard development**.

---

## 👩‍💻 My Role

- Cleaned and processed large-scale taxi datasets using Python  
- Handled missing values, outliers, and inconsistent records  
- Built a scalable pipeline to merge monthly datasets  
- Performed exploratory data analysis (EDA)  
- Generated insights to support revenue optimization  

---

## 📊 Key Insights

- Peak demand occurs between **9 AM – 6 PM**, with ~8% higher revenue  
- Certain locations generate up to **13% of total revenue**  
- Tip behavior is influenced by trip distance and demand patterns  
- High-demand zones significantly impact driver earnings  

---

## 🚀 Business Recommendations

- Focus on **peak hours and high-demand days** to maximize revenue  
- Prioritize **top-performing locations** for better trip frequency  
- Avoid low-demand periods to reduce idle time  
- Optimize trip routes to improve customer satisfaction and tips  

---

## 🧹 Data Cleaning & Processing

- Fixed zero and unrealistic trip distances  
- Handled negative and missing tip values  
- Validated key financial and trip-related columns  
- Processed large files using **chunk-based reading (500K rows per chunk)**  

---

## 📊 Dataset

- Source: NYC Taxi & Limousine Commission (TLC)  
- Size: **40M+ rows**  
- Each row represents a single taxi trip including:
  - pickup/dropoff time  
  - trip distance  
  - fare & tip amount  
  - locations  
  - payment type
